# GH-900 Interactive Foundations

An interactive, hands-on companion to the official Microsoft Learn **GitHub Foundations Part 1 and Part 2** curriculum and the current **GH-900: GitHub Foundations** exam objectives.

The project preserves 1:1 curriculum coverage at the module and unit level, then adds practical GitHub activities, automated validation, and original exam-style checks.

> Source of truth: Microsoft Learn GitHub Foundations Part 1/2 and the GH-900 study guide. This repository paraphrases and extends the concepts; it does not reproduce Microsoft Learn course text verbatim.

Course implementation is being built in verified checkpoints. See `docs/COVERAGE.md` once the bootstrap checkpoint lands.
