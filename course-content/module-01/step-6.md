## Step 6 — Collaboration concepts and assessment

Finish the official exercise coverage, then complete the blind knowledge check.

### Remote collaboration review

On `lab/module-01-git`:

1. Run `git remote -v` and identify `origin`.
2. Run `git fetch` and recall that fetching downloads remote refs/objects without automatically integrating them into your current branch.
3. Run `git pull --ff-only` to synchronize when a fast-forward is possible.
4. Review these terms before the assessment:
   - **clone** — create a local repository copy including history;
   - **push** — publish local refs/commits to a remote;
   - **pull** — obtain and integrate remote-tracking changes;
   - **pull request** — propose changes for review/integration on a hosting platform such as GitHub.
