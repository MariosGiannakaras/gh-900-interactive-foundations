# Module 7 — Manage your work with GitHub Projects: Interactive submission

Read `modules/07-github-projects/README.md` first. Work on branch `lab/module-07`.

## Hands-on activities

1. Create a GitHub Project in your user account or organization and add at least three test items/issues.
2. Create or inspect table, board, and roadmap-style views where available.
3. Add at least one custom field and use filtering/grouping/sorting.
4. Configure or inspect a built-in project workflow/automation such as setting status when an item is added or closed.
5. Inspect project insights/charts where available and explain what question the visualization answers.
6. Compare current GitHub Projects with the historical Projects Classic model described in the module.
