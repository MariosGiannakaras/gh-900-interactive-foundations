1. Open the Python exercise in this repository in VS Code/Codespaces.
2. If Copilot is available, use it to explain the starter code and propose one improvement; review the suggestion rather than accepting blindly.
3. Implement the requested Python change yourself or with Copilot assistance, then run the included checks/tests.
4. Use Copilot Chat (or the documented simulation if unavailable) to propose tests or edge cases and compare them with your own reasoning.
5. Record one example where you changed/rejected an AI suggestion because of correctness, maintainability, security, or clarity.
