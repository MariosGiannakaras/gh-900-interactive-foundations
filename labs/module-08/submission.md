## Hands-on activities

Create `labs/module-08/markdown-practice.md` and demonstrate all of the following in meaningful content:

- at least two heading levels;
- bold and italic emphasis;
- ordered and unordered lists;
- a task list;
- an inline-code span and fenced code block;
- a link;
- an image using Markdown syntax;
- a blockquote;
- a table;
- one GitHub-flavored reference such as an Issue/PR number, commit SHA, username mention, or alert/callout where supported.

Preview the rendered Markdown on GitHub and correct formatting problems before marking the activity complete.
