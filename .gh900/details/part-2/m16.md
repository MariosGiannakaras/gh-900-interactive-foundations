# Source-audited additions — Module 16

## m16-u01

This module applies Copilot to an actual Python development task rather than treating AI assistance as a feature tour. The workflow is iterative: understand the requested behavior, ask Copilot for a focused implementation or explanation, inspect the generated Python, run it, use tests/errors as feedback, refine the prompt or code, and keep only changes you understand and can verify.

Copilot is most useful when the prompt supplies relevant context: the API or function that must be implemented, expected inputs/outputs, error cases, library constraints, and the surrounding code/tests. A generated solution is a proposal, not an oracle. Python code that looks syntactically plausible may still mishandle types, exceptions, boundary conditions, network/API behavior, or security-sensitive data.

The practical objective is therefore twofold: learn how Copilot can accelerate coding and debugging, and practice the engineering discipline needed to validate AI-generated work through reading, execution, tests, and ordinary repository review.

## m16-u07

At completion you should be able to use Copilot as part of a repeatable Python workflow: state the problem precisely, provide useful context, evaluate suggestions, run/tests the result, diagnose failures, and iterate. The quality of the final code remains the developer's responsibility even when Copilot generated most of an initial implementation.

Keep AI assistance inside the same controls used for human-authored code: do not paste secrets unnecessarily, verify third-party/API assumptions, review dependencies and generated commands, follow repository style/security requirements, and use pull-request review and automated tests before integration. Copilot can reduce mechanical effort and help explore alternatives, but correctness is demonstrated by evidence—not by the confidence or fluency of the suggestion.

The hands-on exercise for this course deliberately requires the Python tests to pass. That is the key lesson of the module: use Copilot to help produce the change, then prove the behavior with executable validation.
