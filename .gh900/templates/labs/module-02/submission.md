# Module 2 — Introduction to GitHub: Interactive submission

Read `modules/02-introduction-to-github/README.md` first. Work on branch `lab/module-02`.

## Hands-on activities

1. Create a GitHub Issue describing a small repository improvement.
2. Create a branch for that work, make at least one commit, and open a Pull Request.
3. Link the Pull Request to the Issue using a closing keyword such as `Closes #...`.
4. Inspect the PR conversation, Files changed view, checks area, and merge options.
5. Inspect repository navigation and settings described in the module, including visibility and collaboration controls. Do not change security-sensitive settings just to complete the lab.
6. Review your Notifications page and identify the difference between watching, participating, and mentions.
