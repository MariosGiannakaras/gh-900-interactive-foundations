# Module 16 assessment questions

## Q1
What is the best role for Copilot when modifying a Python project?
- [ ] A. Sole authority that replaces tests and code review.
- [ ] B. An assistant that can suggest/explain code while the developer remains responsible for understanding, testing, and reviewing changes.
- [ ] C. A Git hosting replacement.

## Q2

- [ ] A. Only the word "fix" with no context whenever possible.
- [ ] B. Credentials so it can test production directly.

## Q3

- [ ] A. AI output can be incomplete or wrong; tests provide executable evidence about expected behavior and regressions.
- [ ] B. Tests change the GitHub subscription plan.

## Q4

- [ ] A. Merge it because it looks professional.
- [ ] B. Reject or modify it to satisfy the requirement, then test/review the result.
- [ ] C. Delete the repository.

## Q5
What is a useful Copilot Chat task for an unfamiliar Python codebase?
- [ ] A. Automatically grant repository admin permissions.
- [ ] B. Disable all security checks.
- [ ] C. Explain code flow, identify relevant files/functions, propose tests, or discuss a refactor with context.

## Q6

- [ ] A. The developer/team accepting the change and the project's normal review/governance process.
- [ ] B. Nobody because AI generated part of it.
