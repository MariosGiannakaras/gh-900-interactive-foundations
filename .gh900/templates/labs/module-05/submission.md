# Module 5 — Introduction to GitHub Copilot: Interactive submission

Read `modules/05-github-copilot/README.md` first. Work on branch `lab/module-05`.

## Hands-on activities

1. If Copilot is available on your account, open it in VS Code/Codespaces and request a small code completion, then inspect and edit the suggestion before accepting it.
2. Use Copilot Chat for one explain/refactor/test-generation task and compare the response with the source code yourself.
3. Review Copilot settings and identify where enablement, language/editor behavior, and policy controls can apply.
4. Practice a troubleshooting checklist: extension/account sign-in, entitlement, network/service status, policy, and editor support.
5. If Copilot is unavailable, complete the same prompt-design and evaluation exercise using the examples in the module; access is not required to pass the theory.
